04 / Pilot notes

Before you send a filing.

Why return INSUFFICIENT instead of forcing an answer?

Guessing risks sanctions. The report identifies the unresolved reference so an associate can check it.

Do we need confidential client discovery to test it?

No. Use a public docket PDF or redacted brief to check for missed conflicts and verify quotations.

How is this different from uploading PDFs into ChatGPT?

A chat summary can smooth over conflicts. This audit checks polarity, isolates competing interpretations, and verifies quotes verbatim.

Do you have SOC 2 certification today?

Not yet. Pilots use public or redacted filings and stateless ZDR endpoints; private deployment is scoped per firm.
